# Preparatório Full Stack (+praTi & Codifica)
Curso preparatório do curso Full Stack (+praTi & Codifica) 2026.

## Conteúdo do curso
Exemplos e exercícios introdutórios sobre linguagem de programação com JavaScript, organizados por tema:

- `1-basics.js` - Conceitos básicos: `console.log`, strings, tipos de dados, variáveis (`let`, `var`, `const`), `null`, `undefined`, operações aritméticas, precedência de operadores, conversão de string para número, incrementos e operadores compostos.
- `2-conditions.js` - Condicionais: comparações, operadores lógicos, `if/else`, `else if`, operador ternário, `switch/case`, verificação de par/ímpar, seleção de maior valor e exemplos de lógica de decisão com autenticação e categorias.
- `3-loops.js` - Estruturas de repetição: `for`, `while`, `do...while`, `for...of`, `forEach`, uso de `break` e `continue`, tabuada, contagem regressiva, soma acumulada, cálculo de média e geração de números primos.
- `4-arrays.js` - Arrays e manipulação de listas: criação de arrays, arrays aninhados, `indexOf`, `push`, `pop`, `sort`, soma de elementos, busca do maior valor, inversão de array e ordenação simples.
- `5-functions.js` - Funções: declaração de funções, parâmetros, retorno de valores, cálculo de soma e média, manipulação de objetos por referência, e funções que operam sobre arrays.
- `atividade-01.js` - Exercícios práticos: par/ímpar, classificação de idade, classificação de notas, cálculo de IMC, cálculo de preço com desconto, ordenação de dois valores, loops e médias com entrada do usuário.
- `package.json` - Dependência do curso para entrada no terminal: `prompt-sync`.

## Instalação
Para executar os exemplos com entrada de dados no terminal, instale a dependência no diretório do projeto:

```bash
npm install
```

Ou instale apenas o `prompt-sync` diretamente:

```bash
npm install prompt-sync
```
